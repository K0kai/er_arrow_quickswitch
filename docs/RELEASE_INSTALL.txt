Arrow QuickSwitch — installation

Requires Windows Elden Ring 1.17.2 (executable file version 2.7.2.0),
Mod Engine 3, and offline play. Close the game before installing.

Keep the extracted folders together:

  ArrowQuickSwitch/
    dist/ArrowQuickSwitch.dll
    licenses/MinHook-LICENSE.txt
    licenses/miniz-LICENSE.txt
    licenses/ImGui-LICENSE.txt
    assets/wheel-game-icons.rgba (optional legacy effect badges)

Add the DLL to your own ME3 profile, replacing the example path with the
actual location on your PC:

  [[natives]]
  path = "C:/Mods/ArrowQuickSwitch/dist/ArrowQuickSwitch.dll"
  load_early = false
  initializer.function = "QuickSwitchInitialize"

Launch through that profile. Hold 1, 2, 3, or 4 for the corresponding arrow or bolt
selector, choose an item, and release to equip. The radial center cancels. Press F10 or Back+Start on an XInput controller to open the settings panel.
Save to apply them without restarting. Bindings can also be edited in
dist/ArrowQuickSwitch.ini.
The mod creates that INI on first launch and adds new settings after updates
without changing your existing values.
The opening and hover sound cues can be disabled with [Audio] Enabled=0.
Set [Switching] CycleSameFamily=1 to keep each wheel within the equipped
ammo type. The default 0 allows normal/great arrows or bolts/ballista bolts.
When a slot is empty, its first wheel selection ignores CycleSameFamily so
any eligible owned ammo of that slot's arrow or bolt families can be equipped.

Version 0.7.0 adds radial, strip, list, and quick-strip selection styles, optional
tap and hold cycling, and configurable camera blocking during radial mouse selection.
The earlier 0.6.3 release was tested in-game on vanilla Elden Ring 1.17.2 and
Reforged 2.3.7.1. The user confirmed compatibility with Convergence 3.0.4.
The new styles and physical controller input still need broader in-game validation.

Press F10 or Back+Start during gameplay for customization. Open a wheel once to populate the
preview, adjust settings, then save. The panel does not pause the game.
The shortcuts are [Controls] SettingsKey and [Controller] SettingsButton.
Clearing both disables the panel; restore either in the INI to enable it again. See CUSTOMIZATION.md for
appearance controls and runtime artwork options.

The DLL filename stays ArrowQuickSwitch.dll across updates. Set your launcher profile to this filename once. Check its version by hovering over it in Windows Explorer or opening Properties > Details.
